# 起身一下 · 桌面宠物设计规格

## 目标

为长时间使用电脑的人提供一个跨平台的离线休息提醒工具。应用常驻桌面，以一只抱着水杯的卡皮巴拉陪伴工作；每个工作周期结束时，通过全屏休息页推动用户离开电脑、走动、喝水或去洗手间。

## 体验范围

- 默认工作 60 分钟，休息 5 分钟；两者均可调整。
- 应用平时以桌面宠物和小面板存在，不要求账号或网络。
- 到点进入全屏休息遮罩，显示倒计时和休息建议。
- 默认提供三种强度：温和、强制休息、严格休息；原型实现推荐的“强制休息”模式。
- 用户可以开始、暂停、跳过当前休息、立即休息，并查看今日完成次数。
- 宠物状态包含待机、提醒、休息、完成四类，动画不阻塞计时逻辑。
- 设置和今日数据使用浏览器本地存储，为后续 Tauri store 持久化保留同一数据结构。

## 视觉方向

软、有机、桌面玩具感。背景使用暖灰与浅米色，主色为鼠尾草绿，橙色作为提醒强调；大面积留白配合细边框、轻阴影和纸张纹理感。宠物用 CSS/emoji 原型承载动作，后续可替换为透明动画素材。

## 技术边界

- 先用 Vite + 原生 TypeScript/CSS 产出可直接运行的前端原型。
- 计时器使用单一状态机，所有 UI 只订阅状态变化，不自行维护计时。
- 后续使用 Tauri 2 包装，同一前端接入系统托盘、开机启动、多屏全屏覆盖和桌面窗口。
- 不在第一版加入云同步、账号、社交、复杂养成或运动检测。

## 验收标准

1. 打开应用即可看到宠物、当前状态、工作倒计时和主要操作。
2. 可以用预设按钮快速验证“工作结束 → 休息遮罩 → 休息结束”的完整流程。
3. 调整设置后，计时器和界面立即反映新的工作/休息时长。
4. 刷新页面后，设置、当前计时状态和今日统计仍可恢复。
5. 休息页有明确的倒计时、起身文案和返回动作；跳过休息会被记录。
