# 起身一下 · 桌面宠物 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a runnable desktop-pet break timer prototype that can later be packaged for Windows and macOS with Tauri 2.

**Architecture:** A Vite vanilla TypeScript frontend owns the shell and visual state. A small timer state machine emits snapshots to the UI and persists settings/statistics in local storage. The UI keeps the pet layer, control panel, and break overlay separate so a later Tauri wrapper can replace browser storage and add native window/tray behavior without changing the core experience.

**Tech Stack:** Vite, TypeScript, CSS, Vitest for timer logic tests, Tauri 2 in the packaging phase.

**Spec:** `docs/superpowers/specs/2026-09-09-break-pet-design.md`

## Global Constraints

- Offline first; no account, network, or remote assets.
- Default work duration is 60 minutes and default break duration is 5 minutes.
- The recommended forced-break mode is the prototype default.
- The UI must remain usable at desktop sizes and support reduced motion.
